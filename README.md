# sensor-fusion

The previous TransFusion project is preserved in [legacy/transfusion](legacy/transfusion/README.md),
including its original LICENSE, configurations, environment scripts, and dataset notes.
Run it from `~/sensor-fusion/legacy/transfusion`; its existing editable installation
has been repointed locally. Raw datasets remain outside Git under `~/data/`.

The repository root is being prepared for a camera/LiDAR/radar entropy-steered
fusion project inspired by Bijelic et al., CVPR 2020. The first milestone is a
verified nuScenes-mini data pipeline; model implementation and training are deferred.
